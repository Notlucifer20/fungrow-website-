FUNNGRO TWO-PAGE WEBSITE PROJECT

Files:
- index.html       Teen-focused landing page
- company.html     Company-focused landing page
- assets/style.css Shared responsive design system
- assets/script.js Mobile navigation
- SEO_AUDIT.pdf    SEO understanding and recommendations

PREVIEW:
Open index.html in a browser. Use the top navigation to switch between the two pages.
Internet is needed only for the optional Google Fonts import and official Funngro links; the website layout itself works offline.

IMPORTANT:
This is an independent concept/student submission, not an official Funngro website. Do not present it as the live company website.
The canonical URLs in the HTML point to the official Funngro teen/company paths as reference metadata. When publishing this concept, update canonical URLs and social preview metadata to the actual hosted URLs, or remove canonical tags if the project is only a portfolio demo.

PUBLISH FREE WITH GITHUB PAGES:
1. Create/sign in to GitHub.
2. Create a new public repository, e.g. funngro-website-project.
3. Upload index.html, company.html, assets/ and this README.
4. Open repository Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select main and /(root), then Save.
7. Wait for GitHub Pages to provide the public website URL.
8. Test both pages on mobile and desktop.
